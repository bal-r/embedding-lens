# Reporting a vulnerability

Report sensitive issues using [GitHub private vulnerability reporting](https://github.com/bal-r/embedding-lens/security/advisories/new).
Include the affected commit, reproduction steps and the impact you observed. Keep credentials,
private footage and personal data out of public issues.

The latest `main` branch is the maintained version. This is a research demo, with no guaranteed
response or patch timeline. For ordinary bugs and reproduction questions, open a public issue.
